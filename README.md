# OPN Builder Score

On-chain reputation dashboard for real OPN builders.

## Overview

OPN Builder Score helps developers build an on-chain reputation profile based on project activity and smart contract interactions.

## Features

- Builder registration
- Reputation score tracking
- Project submission system
- Wallet-based identity
- Future leaderboard integration

## Vision

Create a transparent reputation layer for builders in the OPN ecosystem.
## Why Trust Matters

Open Finance has solved access.

The next challenge is trust.

OPN Trust Layer explores how decentralized ecosystems can establish credibility through transparent and verifiable on-chain activity.
